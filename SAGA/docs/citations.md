# Citation preparation

The SAGA author list, thesis title, institution and public repository URL are pending. Add those before release, then provide a real `CITATION.cff`. Include the exact tagged software version and the model/data reference appropriate to each result.

Use the citation instructions from the primary projects for dependencies:

- [MACE source and citation guidance](https://github.com/ACEsuit/mace)
- [ASE citation guidance](https://ase-lib.org/ase/cite.html)
- [scikit-learn citation guidance](https://scikit-learn.org/stable/about.html#citing-scikit-learn)
- [PyTorch project](https://pytorch.org/)

The fine-tuned model is a separate scientific artifact: document its training reference method, domain, source model, data provenance, validation and redistribution terms. A model hash supports identity but is not a substitute for that description.
